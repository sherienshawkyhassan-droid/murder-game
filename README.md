# Murder at the Blackwood Manor

A graphical, choice-driven locked-room murder investigation built with Python and Tkinter.

## Features

- Seven scene-specific cinematic images
- Evidence inventory and three suspects
- Branching interviews and a timed danger sequence
- Multiple endings and a suspense soundtrack
- One-click Windows executable builder

## Run the game

```bash
python -m pip install -r requirements.txt
python blackwood_manor.py
```

Windows users can instead double-click `install_and_play.bat`.

## Create the Windows executable

Double-click `build_exe.bat`. The result appears at:

```text
dist/Murder_at_the_Blackwood_Manor.exe
```

All characters and events are fictional.
